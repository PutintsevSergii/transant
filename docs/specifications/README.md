# TransANT website specifications

This directory contains implementation-facing requirements for the independently designed TransANT website.

- [Agent instructions](../../AGENTS.md), [current status](../../STATUS.md), [change log](../../CHANGELOG.md), and [harness design](../../agent/HARNESS.md) define the long-running implementation loop and handoff contract.
- [Technical requirements](technical-requirements.md) defines the production architecture, functional scope, quality targets, delivery constraints, and acceptance criteria.
- [V7 component-first development plan](v7-component-development-plan.md) is the implementation sequence for Terra: isolated components first, page assembly second, then release integration.
- [Component implementation status](component-implementation-status.md) is the canonical package-by-package completion and evidence tracker.
- [Site structure, UX, and marketing strategy](site-structure-and-ux-strategy.md) defines the audience journeys, information architecture, page blueprints, conversion model, visual direction, and launch priorities.
- [Historical Stitch materials](../../prep/README.md) are retained under `prep/design/`; V7 is the visual reference, while generated HTML and old prompts are not production inputs.
- [Technology stack decision](../technology-stack-decision.md) records the evaluated alternatives and explains why the selected stack fits the project.
- [Original website brief](../original-website-one-week-brief.md) defines the creative boundary, first-release scope, and one-week delivery plan.
