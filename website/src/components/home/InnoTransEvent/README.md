# `InnoTransEvent`

`InnoTransEvent` is a temporary, server-rendered homepage announcement for a confirmed trade-fair appearance. It owns the dark editorial event panel and decorative Linz-to-Berlin rail schematic, while dates, location, copy, external destination, and accessible new-tab notice remain caller-owned.

The component contains one `h2`, one factual event-details group, and exactly one native external `Action`. Its decorative route diagram is excluded from the accessibility tree and makes no live route, timetable, stand, launch, certification, or partnership claim. There is no client controller or motion dependency, so the complete invitation and official exhibitor-profile link remain available without JavaScript and under reduced-motion preferences.

Compact compositions keep the announcement text, date/location, action, and technical card in that order. The action spans the narrow container, while the card remains fully contained. At 60rem of component width the content and card form the approved V9-inspired split. Remove the component from the three homepage assemblies when the campaign ends; adjacent sections do not depend on its markup.
