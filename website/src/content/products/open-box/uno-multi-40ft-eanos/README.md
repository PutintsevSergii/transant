# UNO MULTI 40ft - Eanos

One wagon. Multiple cargo solutions.

The UNO MULTI 40ft Eanos is a versatile open-top wagon engineered for the efficient transport of bulk, heavy and high-density commodities. With a loading volume of up to 73 m³, it combines generous capacity with an optimized tare weight.

Its full-length side doors provide easy access along the entire wagon, supporting fast and flexible loading and unloading while adapting to different handling requirements.
