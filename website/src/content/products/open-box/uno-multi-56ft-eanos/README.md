# UNO MULTI 56ft - Eanos

More volume. More cargo. More efficiency.

The UNO MULTI 56ft Eanos is a high-capacity open-top wagon engineered for the efficient transport of bulk, heavy and high-density commodities. With a loading volume of up to 100 m³, it enables operators to move larger quantities per train.

Its optimized lightweight construction provides an excellent payload-to-tare ratio, while the robust steel body is built to withstand demanding industrial conditions. Full-length side doors provide convenient access along the wagon.
