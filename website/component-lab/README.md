# Component lab

This Astro input tree renders deterministic component fixtures without importing production pages, route state, content collections, environment variables, or deployment adapters.

## Fixture contract

Every fixture must:

- receive explicit serializable fixture data;
- render essential content and navigation in server HTML;
- use only local assets and shared semantic tokens;
- expose one stable route below `/fixtures/`;
- work at the canonical Playwright widths with no page-level overflow;
- support keyboard focus, reduced motion, and axe scanning;
- remain excluded from the production `dist/` output.
